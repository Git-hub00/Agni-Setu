# Evidence directory

Generated test results, screenshots, scan reports and drill logs are written here by the
scripts under `scripts/ci` and `scripts/ops`. Everything except this README is gitignored:
evidence may contain synthetic case data and tool output that must be reviewed before
sharing. Never write real personal data, secrets or signed URLs here.

The authoritative index of evidence IDs is `docs/21_IMPLEMENTATION_STATUS.md` together with
`handover.md` section B7; artifacts in this folder are referenced from those records.
