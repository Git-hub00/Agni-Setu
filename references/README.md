# Read-only prototype reference

This HTML is a byte-for-byte copy of the supplied Agni Setu browser prototype. Open it locally to inspect navigation, layout, text hierarchy and illustrative case data. It contains simulated identity, sample providers and browser-local persistence. Do not reuse these shortcuts in the production implementation.

The new functional, security and architecture specifications take precedence over prototype shortcuts. The HTML is a source reference, not a deployed application, approved legal workflow or evidence that the new backend exists.
